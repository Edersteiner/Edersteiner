# Gabriel Eder

Engine, tools and systems programmer from Sweden, studying at Futuregames Stockholm. Mostly C++, Vulkan, Slang and AngelScript, with Unreal Engine and Godot on the game side.

[gabrieleder.com](https://www.gabrieleder.com) · [LinkedIn](https://www.linkedin.com/in/gabriel-eder-278a1b381/) · gabriel.eder@me.com

## Projects

**[Gibbon Engine](https://www.gabrieleder.com/projects/gibbon)**, 2026. A Vulkan game engine and editor from scratch in C++20: render graph, GPU-driven rendering, ray-traced GI and reflections, AngelScript scripting with generated bindings, and a full editor. Private for now.

**[Fate](https://www.gabrieleder.com/projects/fate)**, 2026. Co-op FPS in a fork of Unreal Engine 5, team of ten. Networked character animation, rain and wet-surface rendering with an engine-side Lumen fix, DLSS integration.

**[Frogga](https://www.gabrieleder.com/projects/frogga)**, 2025. Physics-based Metroidvania vertical slice in Godot and C#. Active-ragdoll animation on Jolt, behaviour tree plugin, physics-aware save system. Audience Choice and Game of the Year at Make A Game.
